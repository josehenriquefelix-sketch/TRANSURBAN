POR QUE O TRANSURBAN EXISTE

O que o projeto busca resolver

01 / O problema que buscamos tratar

Informação difícil de relacionar

Quando cidades, linhas e seus vínculos ficam dispersos, consultar e manter os dados se torna mais difícil. O projeto parte dessa necessidade de organização.

02 / A solução proposta

Uma base integrada

Reunir os registros em um banco de dados e disponibilizá-los por uma API, com uma interface acessível para cadastrar, relacionar e consultar as informações.

03 / O que funciona nesta etapa

Cidades e linhas conectadas

Cadastro e consulta de cidades e linhas, validação dos campos e vínculo com uma cidade existente. Essa é a base para futuras etapas do projeto.

Sobre os dados: as consultas mostram os registros do banco conectado, que ainda inclui demonstrações. A conciliação com fontes oficiais está pendente. O sistema ainda não informa horários, localização de ônibus ou atrasos em tempo real.
