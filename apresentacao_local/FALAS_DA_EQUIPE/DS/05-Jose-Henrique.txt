Tempo de fala: 45–60 segundos, mais os cliques

NA TELA — NÃO PRECISA LER
1. Em POST /cidades, cadastre {"nome":"Maringá"} e copie o id_cidade retornado.
2. Em POST /linhas, use {"codigo":"DEMO-01","nome":"Linha de demonstração","id_cidade":ID_COPIADO}. Troque ID_COPIADO pelo número recebido.
3. Execute GET /linhas para conferir. Se o Swagger não carregar, use /console.

SUA FALA

A API recebe os pedidos, valida os campos e acessa o banco. Vamos cadastrar uma cidade e usar o ID recebido para cadastrar uma linha. POST cria o registro e GET consulta o que foi salvo. Se a cidade não existir, a resposta é 404; se os dados forem inválidos, é 422. Essas respostas ajudam a identificar o problema. Nesta versão, 39 verificações passaram em um banco de teste separado. Esse é o funcionamento local que estamos apresentando. Obrigado!

SE O PROFESSOR PERGUNTAR
Qual a diferença entre model e schema?
O model descreve a tabela do banco. O schema valida a entrada e define o formato da resposta.
