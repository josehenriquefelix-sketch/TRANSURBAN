# Demonstração completa da API no auditório

`GUIA_COMPLETO_API_AUDITORIO.pdf` abre no navegador e serve para leitura/ensaio. O `.docx` é editável no Word ou importável no Google Docs; o `.md` é a fonte. Não são slides.

O guia reúne abertura, sequência de testes, falas da equipe, DS e IA em partes separadas, resultados esperados, explicação dos arquivos, perguntas de apoio e encerramento. No telão, mostre o Swagger da API funcionando em `/docs` no computador que executa o servidor. O documento orienta a equipe e não comprova execução por si só.

O pacote somente sistema permanece separado em `pacotes/TRANSURBAN-SOMENTE-API-E-SITE.zip`; os documentos não são necessários para iniciar a API/site e não foram adicionados a esse ZIP.

Os indicadores citados foram conferidos contra `dados_publicos.resumo()`. DOCX reaberto e PDF de texto pesquisável verificado. A visualização de uma página do PDF foi inspecionada; o documento Word/Google Docs deve ser ensaiado no aplicativo da equipe. Não houve teste de projetor ou controle do computador do auditório.
