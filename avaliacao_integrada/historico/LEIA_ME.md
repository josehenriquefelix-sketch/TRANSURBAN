# Fontes anteriores — não iniciar por esta pasta

Este diretório preserva os exercícios, telas e scripts SQL das etapas anteriores. Eles não são a versão ativa do site e podem depender de um modelo de banco que foi arquivado em 24/11/2026.

A primeira versão que ficava na raiz foi guardada em `primeira_versao/`, para evitar abrir o site antigo ou instalar o requirements errado. O código atual está em `avaliacao_integrada/backend` e `avaliacao_integrada/frontend`, fora desta pasta.

Para executar, use `INICIAR_TRANSURBAN.cmd` da raiz ou abra o workspace. Para preparar outro computador, siga `../PASSO_A_PASSO_ESCOLA.md`. Não execute os scripts SQL históricos sobre o banco atual de 12 tabelas.
