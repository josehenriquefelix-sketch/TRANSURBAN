# TRANSURBAN

## Sistema de apoio ao transporte coletivo de Maringá e Sarandi

O TRANSURBAN é um projeto de sistema de apoio ao planejamento e gerenciamento de faixas exclusivas para ônibus.

## Problema

O trânsito entre Maringá e Sarandi pode contribuir para atrasos no transporte coletivo, prejudicando a mobilidade dos passageiros.

## Proposta

O sistema busca auxiliar na identificação de trechos com ocorrência de atrasos e no gerenciamento de faixas exclusivas ou preferenciais para ônibus.

## Objetivo

Organizar informações sobre cidades, linhas de ônibus, trechos viários, faixas destinadas ao transporte coletivo e registros de atrasos, permitindo analisar pontos críticos e apoiar decisões relacionadas à mobilidade urbana.
