# Pacote reduzido para a apresentação de 20/10/2026

[Baixar ZIP](https://raw.githubusercontent.com/josehenriquefelix-sketch/TRANSURBAN/entrega/escola-apresentacao-2026-10-20/pacotes/TRANSURBAN-APRESENTACAO-20-10.zip).

Extraia o arquivo inteiro e abra `LEIA_PRIMEIRO.txt`. Inclui API Python, site, fonte IA, roteiro sem slides e falas da equipe. Não inclui `.env`, banco de contas, Python nem ambientes virtuais. Python 3.12 e internet são necessários na primeira instalação.

O ZIP tem manifesto SHA256 dos arquivos; o arquivo `.zip.sha256` ao lado permite conferir o próprio download. O código usado está identificado no manifesto interno. Arquivos posteriores publicados no repositório não entram automaticamente neste ZIP.

Windows: na pasta `backend_escola`, execute `PREPARAR-WINDOWS.cmd` e depois `APRESENTAR-WINDOWS.cmd`. Linux: siga `LEIA_PRIMEIRO.txt`. Não execute arquivos diretamente de dentro do ZIP.

Carteira e VT são demonstrações. Tarifa integral urbana de Maringá: R$ 5,80 desde 12/07/2026, conforme fonte da Prefeitura incluída. Itinerários oficiais e GPS da frota não foram incorporados.
